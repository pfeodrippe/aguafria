# Kenney model selection

This directory intentionally contains only the small model subset selected for
Recife Factory. The source is the user's local **Kenney Game Assets All-in-1
3.6.0** archive.

- `factory/`: Factory Kit 3.0 conveyors, machine, hopper, box, and crane.
- `recife/`: Nature Kit 2.1 palm/bridge/canoe and City Kit Industrial 1.0
  building/tank.

All three packs are published under Creative Commons Zero (CC0 1.0). Their
original `LICENSE.txt` files are retained beside the selected models. Kenney does
not require attribution, but the project credits **Kenney — https://kenney.nl/**
because these assets are delightful and useful.

The GLB files are source assets. The Aguafria asset preparation step will reduce
them to the compact vertex/material data actually used by the standalone binary.
